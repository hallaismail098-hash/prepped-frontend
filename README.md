# Prepped — Frontend

The frontend for **Prepped**, an explainable, sentiment-aware multimodal assessment 
system for automated interview and presentation competency evaluation.

Built with React (Vite) and Tailwind CSS, this app lets users record or upload 
interview/presentation responses and view their evaluation results — including 
scores across answer quality, speaking skills, confidence, and facial expression.

## Tech Stack
- React + Vite
- Tailwind CSS

## Related Repo
Backend (FastAPI, scoring engine): [prepped-gp](https://github.com/hallaismail098-hash/prepped-gp)

## Project Context
Graduation project, validated at a Kendall τ ≈ 0.61 against 317 expert-rated samples.
